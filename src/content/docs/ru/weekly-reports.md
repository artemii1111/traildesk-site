Вкладка **Отчёты** на странице бэклога показывает по одному отчёту на неделю. Числа недели (закрыто, пришло новых,
дни с выкладкой) считаются по GitHub — повторять их в тексте не нужно.

Для текущей недели ИИ раз в день и при каждом изменении недели пишет черновик по закрытым задачам; страница помечает
его «подготовлен автоматически». Завершённые недели не трогаются. Для недели без отчёта показывается просто список
закрытых задач.

## Отчёт вручную

Положите файл `ГГГГ-ММ-ДД.md` (понедельник недели) в `.traildesk/reports/` в ветке `main` репозитория проекта.
Что заполнено в файле, главнее черновика ИИ; остальное по-прежнему допишет ИИ.

Пишите для человека, который не видел кода: что изменилось для покупателя или сотрудника, где это посмотреть, куда
нажать. Два-четыре сюжета — главное, а не всё подряд (полный список задач страница покажет сама). Только
проверенное: прежде чем писать «на сайте», посмотрите в окне задачи, что правка уже выкачена.

```
# Заголовок недели — одна мысль, как в газете

Коротко: одна строка для карточки «Отчёт недели».

Лид — абзац-два: что главное случилось и что это значит.

## Сюжет

Абзац: что изменилось, простыми словами.

1. Шаг, как посмотреть
2. Ещё шаг

Ссылка: https://shop.example/… — подпись ссылки
Задачи: #499 #503

## Что дальше

- #418 — одна строка про следующую задачу
```

Строки `Коротко:` (суть одной строкой), `Ссылка:` и `Задачи:` и нумерованные шаги необязательны. Всё остальное
становится абзацем сюжета.
