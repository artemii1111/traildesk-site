ИИ подключать необязательно: без него работает всё, кроме выжимок задач, карточки вопроса, разбора задач (тип и раздел)
и текста отчёта недели.

## Провайдер

**Настройки → Пространство → ИИ**: выберите провайдера — адрес API и пример модели подставятся сами, — затем вставьте
ключ и нажмите **Проверить**. Подходит любой сервис с OpenAI-совместимым API Chat Completions:

| Провайдер | Адрес API | Пример модели |
|---|---|---|
| OpenRouter (сотни моделей) | `https://openrouter.ai/api/v1` | `openai/gpt-4o-mini` |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |
| Anthropic | `https://api.anthropic.com/v1` | `claude-haiku-5-5` |
| Google Gemini | `https://generativelanguage.googleapis.com/v1beta/openai` | `gemini-2.5-flash` |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| Mistral | `https://api.mistral.ai/v1` | `mistral-small-latest` |
| Groq | `https://api.groq.com/openai/v1` | `llama-3.3-70b-versatile` |
| Ollama (свой сервер) | `http://ollama:11434/v1` | `llama3.1` — ключ не нужен |

Проект может использовать свою модель для каждой функции (**Проект → ИИ в проекте**). Если провайдер недоступен
с сервера напрямую, укажите прокси.

Лучше брать быстрые модели без рассуждений: выжимки короткие, а рассуждающие модели тратят бюджет ответа на размышления.

## Расходы и лимит

Каждый запрос записывается вместе с токенами и стоимостью. В **Пространство → ИИ** видны расходы за текущий месяц
по каждому проекту.

- OpenRouter сам сообщает стоимость каждого запроса.
- Для остальных провайдеров укажите **цену за 1M токенов** модели (на входе и на выходе) — иначе стоимость неизвестна.
- **Лимит в месяц, $** — когда расходы до него доходят, ИИ останавливается до следующего месяца; всё остальное
  продолжает работать.

## Приватность

Тексты задач и фрагменты переписки отправляются выбранному провайдеру. Номера телефонов и адреса e-mail перед
отправкой удаляются. Текст из задач в промптах считается недоверенными данными. Если нужен полный контроль, запустите
локальную модель в Ollama.
